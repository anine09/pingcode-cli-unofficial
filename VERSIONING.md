# Versioning

The versioning and release process contract lives in the project spec — do not
duplicate it here:

- **[.trellis/spec/guides/versioning.md](.trellis/spec/guides/versioning.md)** — the single
  source of truth for semantic versioning and the GitFlow release flow (tagging, release
  branches, and the CI workflows that publish a version).
- **[.trellis/spec/guides/gitflow.md](.trellis/spec/guides/gitflow.md)** — branch-based
  development rules.
- **[.trellis/spec/guides/commit-conventions.md](.trellis/spec/guides/commit-conventions.md)** —
  commit message format, including the version-bump commit convention.
